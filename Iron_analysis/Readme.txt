To reproduce US-NHANES Iron analysis, you simply launch here:

source('Iron_analysis_US-NHANES.R') # Run it in R Studio


To reproduce KNHANES Iron analysis, go to the next folder "KNHANES" and READ Readme.txt there in detail!

To reproduce UK-NDNS Iron analysis, it is located in UK-NDNS_Confounding_analysis as "UK-NDNS_Iron_analysis.R". But you should first read and follow Readme.txt in that folder and carry the whole pipeline there before carrying out Iron analysis.
